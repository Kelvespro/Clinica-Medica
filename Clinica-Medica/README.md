# Clínica Médica – Projeto de Banco de Dados

## Descrição
Projeto acadêmico de banco de dados para gestão de clínica médica.

## Estrutura
- `Modelagem/` - MER e DER
- `SQL/` - Scripts de criação, inserção e consultas

## Tecnologias
- MySQL 8.0
- MySQL Workbench

## Como usar
1. Execute `01_create_database.sql`
2. Execute `02_insert_data.sql`
3. Execute `03_queries.sql` para testar
